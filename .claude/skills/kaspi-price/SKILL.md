# kaspi-price

> Статус: заготовка. Кода нет.

## Назначение

Получить цены одного товара на Kaspi.kz по контракту из [`TASK.md`](../../../TASK.md).

## Вход

- Ссылка на карточку товара, например
  `https://kaspi.kz/shop/p/asus-15-6-16-gb-ssd-512-gb-dos-x515ea-bq970-90nb0ty2-m02zn0-108345103/?c=750000000`,
  или ID товара (`108345103`, последнее число в URL).
- Код города (необязательно), по умолчанию `750000000` (Алматы).

## Выход

```json
{
  "product_id": "108345103",
  "title": "...",
  "regular_price": 0,
  "sale_price": 0,
  "city": "750000000",
  "checked_at": "ISO 8601"
}
```

- `regular_price` ← `unitPriceBeforeDiscount`
- `sale_price` ← `price`
- Рассрочку не возвращаем.
