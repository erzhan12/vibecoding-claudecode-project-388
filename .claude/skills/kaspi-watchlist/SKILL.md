# kaspi-watchlist

> Статус: заготовка. Кода нет.

## Назначение

Хранить список товаров, за которыми следит трекер цен.

## Вход

Команда и аргумент:

- `add <ссылка или ID>` — добавить товар;
- `remove <ID>` — удалить товар;
- `list` — показать список.

## Выход

Текущий список товаров, на каждый:

```json
{
  "product_id": "108345103",
  "url": "https://kaspi.kz/shop/p/...-108345103/",
  "title": "...",
  "added_at": "ISO 8601"
}
```
