# kaspi-discount-check

> Статус: заготовка. Кода нет.

## Назначение

Поймать момент скидки: пройти по списку из `kaspi-watchlist`, получить цены через `kaspi-price` и сравнить с историей.

## Вход

- Список товаров из `kaspi-watchlist`.
- История цен из прошлых проверок.

## Выход

Отчёт по каждому товару:

| Товар | regular_price | sale_price | Скидка | Изменение с прошлой проверки |
|-------|---------------|------------|--------|------------------------------|

Отдельно — товары, у которых появилась скидка (`sale_price < regular_price`) или `sale_price` стал ниже, чем в прошлый раз.
