# Скиллы трекера цен Kaspi.kz

Скиллы Claude Code для отслеживания цен на ноутбуки в Kaspi Магазине.
Цель и контракт проекта описаны в [`TASK.md`](../../TASK.md).

> Статус: заготовка. Кода парсинга пока нет, у каждого скилла описаны только назначение, вход, выход и открытые вопросы.

## Контракт полей

| Поле           | Источник на Kaspi         | Смысл                  |
|----------------|---------------------------|------------------------|
| `regular_price`| `unitPriceBeforeDiscount` | цена без скидки        |
| `sale_price`   | `price`                   | текущая цена продажи, `null` если скидки нет |
| `has_credit`   | `loanAvailable` из каталожного API (неофициальный) | есть ли рассрочка; `null`, если запрос не удался |

Скидка есть, когда `sale_price < regular_price`.

## Скиллы

| Скилл                                                   | Что делает                                                    | Статус    |
|---------------------------------------------------------|---------------------------------------------------------------|-----------|
| [`extract-price`](extract-price/SKILL.md)               | Получает `regular_price`, `sale_price` и `has_credit` по ссылке на карточку | заготовка |
| [`tracker`](tracker/SKILL.md)                           | Прогоняет `extract-price` по зашитому списку ссылок, отдаёт одну таблицу цен за запуск, сравнивает её с прошлым снимком и сохраняет снимок в `tracker-data` | работает  |
| [`kaspi-watchlist`](kaspi-watchlist/SKILL.md)           | Ведёт список отслеживаемых ноутбуков: добавить, удалить, показать | заготовка |
| [`kaspi-discount-check`](kaspi-discount-check/SKILL.md) | Сравнивает цены с историей и сообщает о скидке                | заготовка |

Как они связаны: `kaspi-watchlist` хранит список товаров, `kaspi-discount-check` проходит по нему, через `extract-price` берёт текущие цены и сравнивает их с историей.

## Как устроен скилл

Каждый скилл — отдельная папка с файлом `SKILL.md`:

```
.claude/skills/<имя-скилла>/
└── SKILL.md
```

`SKILL.md` начинается с frontmatter:

```yaml
---
name: <имя-скилла>
description: <когда и зачем вызывать скилл; по этому тексту Claude решает, подходит ли он>
---
```

Дальше идёт инструкция для Claude. Скрипты и вспомогательные файлы можно класть в ту же папку и ссылаться на них из `SKILL.md`.

## Как добавить новый скилл

1. Создать папку `.claude/skills/<имя-скилла>/` (имя в kebab-case, с префиксом `kaspi-`).
2. Добавить `SKILL.md` с frontmatter `name` и `description`.
3. Описать разделы: «Назначение», «Вход», «Выход», «Шаги», «Открытые вопросы».
4. Добавить строку в таблицу «Скиллы» выше.
